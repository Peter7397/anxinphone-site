Anxin Phone — simple iPhone for family (Elder & Student modes)

Developer: 陈平根 (Pinggen Chen)

Getting started

  1. Install Anxin Phone on the iPhone that will be used daily.
  2. Grant Screen Time permission during onboarding.
  3. Choose Elder or Student, select apps/schedules, and set a caregiver PIN.
  4. (Elder) Add favorite numbers; optionally install the call-protection Shortcuts helper.

Caregiver PIN

  • Elder: long-press 菜单 to open caregiver settings.
  • Student: long-press the grade icon to open parent settings.
  • There is no cloud PIN recovery — forgetting the PIN requires resetting app data.

Common issues

  • Apps not blocked: Confirm Screen Time permission is approved and restrictions are enabled.
  • Call protection: Some Phone settings need the optional Shortcuts helper or a one-time manual Settings change.
  • SMS / WeChat menus: Show caregiver-entered preview text only — not live message sync.

支持

安心手机（Anxin Phone） — 家人用的简单 iPhone（老人 / 学生模式）

开发者：陈平根

快速上手

  1. 在日常使用的 iPhone 上安装安心手机。
  2. 在引导流程中授予屏幕使用时间权限。
  3. 选择老人或学生，设置应用/日程，并创建看护人 PIN。
  4. （老人）添加常用号码；可选安装来电保护快捷指令助手。

看护人 PIN

  • 老人：长按「菜单」打开看护设置。
  • 学生：长按年级图标打开家长设置。
  • PIN 无法云端找回，忘记后需重置应用数据。

常见问题

  • 应用未被屏蔽：请确认已授权屏幕使用时间且限制已开启。
  • 来电保护：部分电话设置需快捷指令助手或一次性手动设置。
  • 短信/微信菜单：仅显示看护人填写的预览文字，并非实时聊天同步。
